## 🚀 Série Principal: DataMart Analytics (5 Projetos)

A **Série DataMart** é um conjunto de 5 projetos incrementais que simulam o ambiente real de uma empresa de e-commerce. Cada projeto evolui o anterior, adicionando camadas de complexidade, segurança e resiliência.

| # | Projeto | Foco Principal | Tecnologias | Link |
| :---: | :--- | :--- | :--- | :---: |
| **1** | **Pipeline Serverless de Vendas** | Fundamentos de Cloud e ETL | Python, Lambda, S3, Athena | [Repositório](https://github.com/bealimav/projeto-1-serverless) |
| **2** | **Pipeline com Terraform** | Infrastructure as Code (IaC) | Terraform, Python, Lambda, S3 | [Repositório](https://github.com/bealimav/projeto-2-terraform) |
| **3** | **Qualidade e Idempotência** | Testes e Prevenção de Duplicatas | Terraform, DynamoDB, Pytest + Mock | [Repositório](https://github.com/bealimav/projeto-3-qualidade) |
| **4** | **Observabilidade e FinOps** | Monitoramento e Controle de Custos | CloudWatch, SNS, Budgets, Terraform | [Repositório](https://github.com/bealimav/projeto-4-observabilidade) |
| **5** | **Analytics de Vendas com IA** | Visualização e IA Generativa | Athena, Amazon Q, Pandas, Matplotlib | [Repositório](https://github.com/bealimav/projeto-5-analytics) |

> 💡 **Nota de FinOps:** Todos os projetos foram construídos aplicando as melhores práticas de FinOps. Toda a infraestrutura na nuvem é provisionada via código e destruída (`terraform destroy`) após os testes, garantindo que o custo final seja **$0,00**.
